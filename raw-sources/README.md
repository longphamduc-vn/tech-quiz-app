# Raw Sources & Materials

Thư mục lưu trữ toàn bộ tài liệu nghiệp vụ gốc (nguồn thô), không phải mã nguồn ứng dụng:

- **`WS/`**: Các tài liệu bài giảng slide PowerPoint (`.pptx`), file bảng điểm (`.xlsx`), hình ảnh scan đáp án bài thi (`.jpg`) dùng cho các bộ đề thi White Star (Điện, PLC, Khí nén, Linh kiện máy).
- **`docs/`**: File tài liệu kỹ thuật tham khảo (`main.pdf`).
